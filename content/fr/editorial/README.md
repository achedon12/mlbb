# Textes signés de l'auteur

Écrits à la main, en français, jamais traduits automatiquement.

- `auteur.md` : la présentation « Qui fait MLBBDex », sur `/about`.
- `patchs/<version>.md` : l'avis sur un patch, sur sa note de patch.
- `tier-list/<version>.md` : l'avis sur la tier list, tant que ce patch est en ligne.
- `_modeles/` : les modèles commentés à copier. Jamais lus par le site.

Rien ne s'affiche tant qu'un fichier n'est pas complet. Guide complet : `docs/editorial.md`.
Vérifier : `npx vitest run tests/unit/editorial.test.ts`.
