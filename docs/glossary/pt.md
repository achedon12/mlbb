# Brazilian Portuguese (pt) game glossary

The site's Portuguese is Brazil's (`/pt`, `lang="pt-BR"`, `hreflang="pt-BR"`).
Brazilian players mix both languages: Portuguese for roles and common words
(herói, atirador, tanque, partida), English for the jargon (build, counter,
tier list, skin, jungle, pick, ban). The machine translation writes
"construção", "contador", "pele", "lista de níveis", and even "Lendas Móveis".

Applied by `scripts/translation-glossary.mjs` (rules `pt`) and by hand in
`scripts/translations-messages-overrides.json`.

| tier list | tier list | lista de níveis |
| win / pick / ban rate | taxa de vitória, taxa de pick, taxa de ban | taxa de proibição |
| ban, pick, draft | ban, banir, pick, draft | proibição, escolha |

Proper nouns stay as the game writes them in English: hero, item, spell,
emblem and talent names ("Retribution", "Flicker", "Fighter Emblem"), MPL,
MSC, MVP.
