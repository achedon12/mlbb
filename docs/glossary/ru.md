# Russian (ru) game glossary

Russian players use the community's jargon, a mix of Russian words and
transliterated English: контрпик, тир-лист, билд, скин, лес и лесник,
стрелок, патч-ноуты. The machine translation writes "счетчик" (a meter),
"кожа" (skin, the organ), "список уровней", "джунгли", "Мобильные легенды".

Russian declines its nouns: the glossary rules (`scripts/translation-glossary.mjs`,
`ru`) list each form the service returns ("счетчики", "счетчиков",
"счетчиками"…). Hand corrections go to
`scripts/translations-messages-overrides.json`.

Proper nouns stay as the game writes them in English: hero, item, spell,
emblem and talent names ("Retribution", "Flicker", "Fighter Emblem"), MPL,
MSC, MVP.
