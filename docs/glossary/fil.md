# Filipino (fil) game glossary

Filipino players write **Taglish**: Tagalog sentences, English game words.
The machine translation renders every game word in deep Tagalog ("bayani",
"balat", "Panginoon") that no player searches for. Rule: Tagalog grammar
(`mga`, `ng`, `sa`, verbs), English nouns of the game.

Applied by `scripts/translation-glossary.mjs` (rules `fil`) on every machine
translation, and by hand in `scripts/translations-messages-overrides.json`.

| Concept | Write | Not |
| --- | --- | --- |
| hero, heroes | hero, mga hero | bayani |
| skin | skin | balat |
| build | build | pagbuo, gusali |
| counter | counter, kinokontra | kontra-atake |
| tier list | tier list | listahan ng antas |
| win / pick / ban rate | win rate, pick rate, ban rate | rate ng panalo |
| ban, pick, draft | ban, pick, draft | pagbabawal, pinili |
| patch notes | patch notes | mga tala ng patch |
| emblem, talent | emblem, talent | sagisag, talento |
| Battle Spell | Battle Spell | combat spell |
| item | item, mga item | bagay, kagamitan |
| skill, ultimate, passive | skill, ultimate, passive | kasanayan |
| damage, cooldown | damage, cooldown | pinsala, recharge |
| roles | Tank, Fighter, Assassin, Mage, Marksman, Support | tangke, tagabaril, salamangkero |
| lanes | Gold Lane, EXP Lane, Mid Lane, Jungle, Roam | gubat, gintong lane |
| objectives | Lord, Turtle, buff, minion | Panginoon, Pagong |
| ranks | Warrior … Mythic, Mythical Honor, Mythical Glory, Mythical Immortal | — |
| daily reset | reset | diskwento |

Proper nouns stay as the game writes them: hero, item, spell, emblem and
talent names, regions of the Land of Dawn, MPL, MSC, MVP.
